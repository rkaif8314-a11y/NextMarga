# Product Roadmap Principles

NextMarga should prioritize improvements that make opportunity discovery more trustworthy and actionable.

Near-term work should favor:

1. Reliable opportunity filtering and clear eligibility information.
2. Better application tracking and deadline visibility.
3. Accessible, responsive student workflows.
4. Stronger validation and test coverage around server endpoints.
5. Useful AI assistance with transparent limitations and safe fallbacks.

New features should solve a documented student problem and include a verification plan before they are considered complete.
