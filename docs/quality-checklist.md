# Feature Quality Checklist

Before considering a feature complete:

- [ ] The happy path works.
- [ ] Empty, invalid, and unexpected input are handled.
- [ ] Loading and error states are understandable.
- [ ] Keyboard navigation works for interactive UI.
- [ ] The layout remains usable on mobile.
- [ ] No secrets or sensitive debug output were introduced.
- [ ] Relevant build or test checks pass.
- [ ] Time-sensitive opportunity claims are backed by an appropriate source.
- [ ] Documentation is updated when setup or behavior changes.

Use this checklist as a lightweight gate for future feature work.
