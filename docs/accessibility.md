# Accessibility Checklist

Use this checklist when adding or changing UI in NextMarga:

- Give every form control a visible label or accessible name.
- Keep keyboard focus visible and preserve a logical tab order.
- Use semantic buttons and links instead of clickable generic containers.
- Provide meaningful alternative text for informative images.
- Do not rely on color alone to communicate status.
- Make validation and async errors understandable to screen-reader users.
- Respect reduced-motion preferences for non-essential animation.
- Check layouts at narrow mobile widths before shipping.

Accessibility should be treated as part of the feature, not as a final polish step.
